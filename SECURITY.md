# Security policy

## Reporting a vulnerability

Please report security vulnerabilities in the Milofly CLI, SDKs or the Milofly platform **privately** by e-mail to
**destek@milofly.com**, not in a public issue or pull request.

Include what you can:

- the affected package and version (for example `@milofly/app-server@0.1.0` or `Milofly.Apps 0.1.0`),
- what an attacker can do, and the steps or a small proof of concept to reproduce it,
- whether the issue is already known publicly.

Never include real secrets (client secrets, signing secrets, access tokens) in the report; revoke any that may have
leaked and regenerate them in the developer portal.

We confirm receipt, keep you informed while we work on a fix, and credit you in the release notes if you wish.

## Supported versions

Fixes are released as a new version of the affected packages. Only the latest released version of each package
receives security fixes.
